这份地图现在记录了什么

现有30条记录：保留26条原有设施，新增4个采集资料中的临时便民点。本轮整理8份交付文件中的12份文档，补充楼层、入口、服务与开放条件，并筛选93张已获授权的现场照片。资料由采集人提供，尚待交叉复核；网站制作人员没有到现场核实。

当前已定位 0 条，待定位 30 条。没有可靠坐标的项目不会放到地图上。地图服务能加载，不代表校内资料已经更新。

沿用已上线网页编号，采集手册的SJ编号另外映射，不按清单序号重排链接。遇到院系归属、日期或入口数量冲突，详情页明确列出差异；采集时营业状态不代表现在实时营业。

真实地图接入与配置

主方案为腾讯位置服务 JavaScript API GL，仅使用官方 SDK。已配置项目网页地图 Key，并通过 localhost 的底图加载与 POI 测试标记显示实测。GitHub Pages 发布域名仍需加入腾讯白名单；建筑点位仍待采集。

  1. 进入腾讯位置服务控制台，创建项目应用和网页地图 Key。
  2. 按平台当前要求配置域名授权，包括本地测试域名和网站发布域名；仅开通需要的客户端权限。
  3. 本包已在 js/config.js 配置浏览器端公开 Key。确认授权实际发布域名后再检查线上加载。
  4. 检查学校附近的校内道路、镜湖、建筑轮廓及移动端加载，逐条核对点位。不要借用官方示例 Key。

腾讯 SDK 使用 GCJ-02，位置构造函数为纬度在前、经度在后。GPS 与 OSM 的 WGS84 记录须先经过有依据的规范转换并保留原始来源，不可直接混用。学校分享坐标仅作为初始查找视图，未核实为校园中心。

配额、授权与收费以你的账号控制台及平台现行条款为准；不能承诺无限免费或校内建筑完全覆盖。SDK 的版权、腾讯标识与比例尺须保留。
