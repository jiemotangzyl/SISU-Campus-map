## 采集与复核步骤

记录 coordinate_system、coordinate_source、coordinate_source_url、coordinate_collected_at、position_type 和原始坐标；把“建筑中心”与“实际入口”分开。采集后状态先为“已定位，待现场复核”，只有真实现场复核后填 verified_at 并改为“已现场复核”。内容状态不可随坐标状态自动升级。

腾讯 SDK 仅绘制 GCJ-02、数值有效、有来源且状态为已定位的点。WGS84 与 BD-09 坐标不会直接绘制。必须经过合规转换并保留 original_coordinates。标准 GeoJSON 为 WGS84 的 [longitude, latitude]，本版 GeoJSON 空集合；点位由 JSON 字段驱动。geometry 是扩展字段，本版不消费，没有可靠轮廓时使用真实点标记。添加轮廓功能必须先准备真实来源与转换，不能把 GCJ-02 冒称标准 GeoJSON。

重点人工复核：二教三教东西栋各自入口、均不互通；小足球场在八教正北、篮球场在八教正西、羽毛球场在篮球场正北；篮球场与羽毛球场之间空地的正东为小足球场。相对方位是核对条件，不是精确坐标。
