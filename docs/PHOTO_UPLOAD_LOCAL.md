# 本地照片上传与管理员相册

运行 `python server/photo_server.py` 后访问 http://localhost:5183/ 。它同时保留原匿名位置共享服务。

- 上传页面：`upload.html`；照片墙：`scenery.html`；管理员页面：`admin.html`。
- 同学无需登录上传，提交前必须确认可公开。上传后立即加入风景墙，打开照片墙或刷新可见；不自动审查图片中的人脸、车牌或内容，上传者需筛选，管理员可随时删除。
- 仅接受JPG、PNG、静态WebP，不超过8MB、2400万像素。服务端真实解码、纠正方向、缩小长边至2000像素，再编码为无EXIF的JPEG，不使用用户文件名作路径。
- 照片与SQLite数据库持久化保存在网站目录之外的 `work/private-photo-library/`。服务重启后仍保留。最多500张、200MB；管理员可删除释放容量。
- 初次启动自动生成随机管理员密码，保存在该私有目录的 `管理员登录.txt`；该文件不在网站公开目录，不应提交到GitHub。
- 管理员密码用PBKDF2校验，登录会话为一小时的HttpOnly、SameSite=Strict Cookie。删除要求管理员会话及同源JSON请求；退出立即使会话失效。页面不会内置密码。
- 管理员可用“添加照片”提交新图，用“删除照片”从照片墙和存储中移除用户上传的照片。原来设施相册的93张照片不受此后台影响。

本版仅监听本机，未开通付费资源，尚不支持其他同学通过公网使用。GitHub Pages不能执行上传后端；上线前需提供HTTPS、持久存储、上传限流和内容管理等实际服务，再确认额度与成本，不能承诺无限免费。正式上线时可重设管理员密码并启用Secure Cookie。
