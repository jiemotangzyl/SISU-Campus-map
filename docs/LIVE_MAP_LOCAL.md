# 匿名活点地图（本地体验版）

运行 `server/presence_server.py` 后访问 http://localhost:5182/ 。仅使用 Python 标准库，无数据库、云账号或新增付费服务。

- 默认关闭，点击“开启匿名共享”后才请求浏览器定位并上传当前位置。
- 只向当前仍在共享的人返回匿名小点，不返回姓名、头像、设备标识、会话令牌或个人资料。
- 前台约20秒更新一次。隐藏页面后停止采集和上传；60秒未更新由服务端移除，客户端也独立清除过期点。正常关闭或离开页面会尝试立即删除，网络失败时仍由60秒有效期兜底。
- 只在服务进程内存保存最新位置，不写入文件、不记录位置请求日志，不保存轨迹。服务关闭即清空。
- 真实模式接收浏览器WGS-84位置，在本机近似换算GCJ-02后绘制。近似换算和设备精度均可能带来误差，不能当作入口或精确导航依据。以校区附近的粗略矩形限制共享范围，并非严格校园围栏。
- “模拟体验”使用随机校园位置，仅代表当前体验会话，不申请定位权限；模拟与真实模式完全分开。同一模式可通过两个标签页或窗口体验多人小点，每页一个临时会话，无虚构的其他用户。
- 绿色小点代表其他匿名会话，蓝色点代表自己，不支持点击查看个人详情。

本地服务只监听127.0.0.1，尚不能让外部手机或其他电脑共同接入。GitHub Pages无法运行这个Python后端。正式部署需要适配可公网访问的HTTPS服务、确认数据访问控制和额度；20秒刷新不能保证任意在线人数零费用。本版未开通任何云服务。浏览器定位也可能因设备、权限或网络不可用，定位失败时不上传旧坐标。

这是自愿匿名展示，并不代表位置不可被认识你的人推断。小点以外不公开任何额外个人资料。
